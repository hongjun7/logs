assumptions. The finite truth-table/logarithm example was checked separately.

## Production compatibility correction

The first Pages run (#282, commit `f37379d`) failed under Jekyll 3.10 with
`comparison of Array with Array failed` while sorting Korean page dates.
YAML date-only values and timestamps compare differently in this runtime.
The failure was reproduced with Ruby `Date`/`Time` comparison. Korean listings
and neighbors now sort by the existing ISO-date-prefixed `translation_key`;
the string-key check and all local site/pair/content checks pass. The English
post order and article contents are unaffected. Production validation requires
a subsequent successful Pages run.
